# pockit-skin

Skin remoto de **PockIt** (modo A+). La app descarga estos archivos al abrir:

- `theme.css` — variables de color de claude.ai con la paleta de Pockit. Solo colores, nunca layout.
- `config.json` — `skinEnabled: false` apaga el skin en todos los dispositivos (modo seguro remoto). Subí `cssVersion` cuando cambies el CSS.

GitHub cachea los archivos Raw unos minutos: un cambio puede tardar en verse.
